## 提出理论

介绍：基于直觉的从零研发，目标是研制高级人工智能。

如果把细胞当成一个生命的话，他们本身就是一个个独立的个体，他们自己会持续不断产生生物电流，当然不可能像计算机的程序那样逐个进行计算，当然是异步计算的。
我的感觉是，每个神经元都是一个微小的微处理器。
也就是说，AI神经网络的节点实际上应该分批部署在微型计算机上，然后通过计算机的引脚进行通讯，实现真正的异步计算。
而最简单的单片机，实际上是能够不需要太多考虑散热问题，因为只需要空气的自然散热，以及一个用来通风的设备就足够了。

skills技能同样是一个单独的神经网络，而不是一段简单的提示词。
只有神经网络与神经网络之间的组合，才能真正带来数字的生命。
